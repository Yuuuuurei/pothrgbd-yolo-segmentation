02 Latar Belakang

Lubang jalan (pothole) merupakan kerusakan infrastruktur yang mengancam keselamatan berkendara. Deteksi manual bersifat lambat dan tidak konsisten.

Pendekatan berbasis deep learning, khususnya instance segmentation, memungkinkan identifikasi lokasi dan bentuk pothole secara otomatis dengan presisi piksel. Penggabungan data RGB dan depth map menambah dimensi geometri kedalaman relatif, penting bagi manajemen jalan.

05 Metodologi
1
Persiapan Dataset
Unduh otomatis via Kaggle API, pasangkan RGB–label–depth, bagi menjadi train/valid/test, buat data.yaml.
2
Pemeriksaan Integritas
Validasi kelengkapan pasangan RGB, label, dan depth .npy, serta format label YOLO polygon.
3
EDA
Analisis distribusi instance per gambar, distribusi area bounding box relatif, dan statistik per split.
4
Training YOLOv8-seg
Fine-tuning YOLOv8n-seg dengan citra RGB, optimasi loss deteksi + segmentasi + distribusi prototipe mask.
5
Evaluasi & Inference
Hitung Precision, Recall, mAP50, mAP50-95 pada split test. Jalankan inference dengan threshold conf 0.40.
6
Analisis Depth
Statistik depth (mean, median, std, Q25/Q75) dalam area mask. Visualisasi profil horizontal & vertikal, surface plot 3D, point cloud .ply.

10 Kesimpulan
Performa Segmentasi Tinggi
YOLOv8-seg mencapai Mask mAP50 = 0.9720 dan Mask Precision = 0.9526 pada test set PothRGBD, membuktikan efektivitas pendekatan instance segmentation untuk deteksi pothole.
Depth sebagai Analisis Lanjutan
Depth map (.npy uint16) dimanfaatkan secara efektif sebagai sumber analisis pascasegmentasi: profil geometri, surface plot 3D, dan distribusi statistik area pothole, tanpa dimasukkan langsung ke model YOLO.
Pipeline Modular & Reproducible
Setiap tahap (setup, EDA, training, evaluasi, analisis depth) dimodularisasi dalam script terpisah. Dataset diunduh otomatis via Kaggle API. Seluruh proses dapat direproduksi dari repository GitHub.
